# KubeManifestPilot Third-Party Notices

Status reviewed: 2026-08-16

## Runtime dependencies

The current KubeManifestPilot distribution does not declare, bundle, or load any third-party JavaScript library, CSS framework, icon library, web font, YAML package, or advertising script at runtime.

Standard browser APIs and web platform features are not bundled third-party packages.

If a third-party dependency is added in a later release, this file must be updated before distribution with its exact name, pinned version, source URL, copyright notice, license identifier, and any required full license or NOTICE text.
