Kubernetes 設定檔產生器

依序回答五個步驟。KubeManifestPilot 只進行靜態規則檢查，不會讀取 kubeconfig、連線或修改 Kubernetes 叢集。

本機處理 · 不上傳回答

選擇範本與專案

先決定應用組成，再設定可重現的 Kubernetes 名稱與環境。

專案資訊

名稱會用於 labels 與預設 Resource 名稱。

小寫英數字與連字號，最長 63 字元。

所有產生的 namespaced resources 都會明確寫入。

Namespace 處理

使用既有 Namespace 時請取消勾選。

設定應用元件

Image、Port 與 Probe 必須符合容器實際行為；產生器不會根據映像名稱猜測。

Frontend

靜態網站或 Web 前端。若映像不是 Nginx，請依實際監聽 Port 調整。

Production 不接受 latest 或缺少版本的 image。

資源、Probe 與進階設定

每行 KEY=value；不要放密碼或 Token。

每行 ENV_NAME=secret-name:key；只保存參照，不輸入 Secret 值。

Backend

API 或服務容器。預設只建立 ClusterIP，由前端或 Ingress 存取。

範例映像預設監聽 5678；換成自有映像時必須同步調整。

資源、Probe 與進階設定

每行 KEY=value；資料庫 Secret 由下一步設定。

每行 ENV_NAME=secret-name:key；只保存參照，不輸入 Secret 值。

設定資料庫與儲存

內建 PostgreSQL 使用 StatefulSet；Production 只允許引用既有 Secret，不在問卷輸入密碼。

內建 PostgreSQL 單副本

適合教學或受控環境，不具 HA、自動備份、PITR 或故障切換。

Production 使用單副本資料庫仍可能因節點、儲存或維護事件中斷；請規劃備份與還原演練。

PRODUCTION 從既有 Secret 讀取，不輸出 User 明文。

PRODUCTION 從既有 Secret 讀取，不輸出 Database 明文。

外部 PostgreSQL

不建立 StatefulSet 或 PVC，只把連線資訊與既有 Secret reference 注入 Backend。

填寫時會從同一個 Secret 讀取 Host，並取代上方 Host。

設定對外方式與可靠性

Backend 預設保持 ClusterIP。Ingress 與 LoadBalancer 只引用叢集已具備的能力。

服務入口

可靠性選項

這些設定只作用於 Deployment；單副本不會自動產生 PDB。

檢查與產生

先解決阻擋錯誤。警告不一定阻擋下載，但代表仍需在目標環境確認風險。
